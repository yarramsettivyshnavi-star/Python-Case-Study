## Syllabus scope
The PDF lists computational thinking, algorithms, flowcharts, pseudocode, variables, data types, operators, conditional statements, loops, strings, pattern generation, lists, nested lists, tuples, tuple operations, and unpacking. Student programs use core Python constructs in that scope and no external packages.
